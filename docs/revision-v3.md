# v3: 팬이 잡아줄까?

2026-10-21 (한국 시간). 사용자와 합의한 방향은 강의형 설명을 줄이고 질문 하나에 집중하는 YouTube Shorts입니다. ‘밑에 달린 팬이 공중에서도 차를 붙잡을까?’를 첫 화면에 던지고, 역할 차이를 답으로 보여준 뒤 마지막 선택 질문으로 마무리합니다. 성과나 알고리즘 노출을 보장하는 변경은 아니며 실제 반응은 게시 후 확인합니다.

## 완성본과 구성

완성 파일: `outputs/first-film-v3/roadster_landing_v3.mp4`. 22초, 720×1280, 24fps, 한국어 남성 내레이션·번인 자막. v1·v2는 별도 파일로 보관합니다.

| 시간 | 역할 | 내레이션 |
| --- | --- | --- |
| 0–3초 | 화면 질문: 밑에 달린 팬이 잡아줄까? | 날아오른 로드스터, 내려올 땐 뭘 쓸까요? |
| 3–6초 | 예상과 다른 답 | 공중에서 땅을 끌어당기는 장치는 아니에요. |
| 6–10.9초 | 공중에서의 힘 | 불꽃 대신 압축 공기를 아래로 뿜어, 하강에 브레이크를 거는 거죠. |
| 10.9–15.9초 | 팬의 역할 | 팬은 역할이 달라요. 차 밑 공기를 빼서 바닥에 붙는 힘을 만듭니다. |
| 15.9–17.8초 | 짧은 발견 | 추진기와 팬, 역할이 다르죠. |
| 17.8–22초 | 시청자 선택 | 여러분은 어떤가요? 아직 무섭다, 아니면 타보고 싶다? |

서스펜션과 정지 시간 설명은 이번 합의에 따라 제외했습니다. 독립된 도식 화면은 없으며, 17.8초까지 기존 움직이는 차량 영상에 짧은 분사 방향·팬 표시만 겹칩니다. 팬의 회전 표시는 실제 내부 구조 영상이 아니라 개념 설명입니다. 17.8초 이후에는 사용자 제공 선택 이미지를 유지합니다. 정지 차량 사진이나 상·하단 AI 고정 문구·주황색 보조 문구는 넣지 않습니다.

## 음성·비용

새 합성 대신 v2의 남성 James 음성 원본을 문장 단위로 재편집했습니다. 첫 질문은 화면의 팬 질문을 보완하도록 기존 ‘내려올 땐 뭘 쓸까요?’를 사용합니다. 없던 단어를 합성했거나 제안 예시 대사를 새로 녹음했다고 주장하지 않습니다. 문장 사이의 공백과 말의 속도만 로컬로 조정하며 피치는 유지합니다.

추가 API 호출·새 영상·새 음성 생성은 없습니다. 이번 추가 사용은 0크레딧, 프로젝트 누계는 영상 75 + 기존 음성 4 = 79크레딧입니다. 마지막 API 확인 잔액 921은 v2 음성 다운로드 시점의 값이며 이번에 다시 조회하지 않았습니다.

기존 음성 ID: `85faff93-22b4-47cf-8852-977a2fba04b3`. 차량은 기존 2번 `82809632-8631-4f42-8b0a-8e6b65cd01d2`, 3번 `cedccc44-f84c-477e-a302-17264defa8a4` 클립만 사용합니다. 생성 재개가 아니라 파일 재활용이며 자동 재생성하지 않습니다.

## 근거와 재현

기술 근거는 [v2 출처 검토](revision-v2.md)를 이어갑니다. ```bash
