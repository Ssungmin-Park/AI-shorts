# v4: 장면 다양성과 음악

2026-10-21. 같은 차량 구도의 반복을 줄여 달라는 사용자 요청과 **144크레딧으로 새 장면 4개 생성** 승인에 따라 Gen-4.5 텍스트→영상 3초 클립을 각각 한 번 생성했습니다. 재생성은 없습니다. 기존 남성 음성·22초 질문 중심 대본·사용자 선택 이미지를 유지합니다.

완성 파일: `outputs/first-film-v4/roadster_landing_v4.mp4`. 한국어, 세로 720×1280, 24fps, 22초. 구버전과 별도 보관합니다. 기술 검사·해시는 `revision-v4-quality.json`, 작업 ID·원본 해시·비용은 `revision-v4-state.json`에 기록합니다.

| 편집 시간 | 장면 | 검수·사용 범위 |
| --- | --- | --- |
| 0–3.8초 | 새 넓은 사선 전경 | 카메라가 차량 옆·뒤로 이동하며 낮게 내려앉고 전진하는 인상. 실제 하강률·추력 검증 불가 |
| 3.8–6초 | 기존 체공 2번 | 원본 0.5초부터 2.2초, 한 번만 사용 |
| 6–10.9초 | 새 후면 분사구 근접 | 후면 추적과 짧은 흰 분사. 정확한 노즐 방향·추력은 측정 불가 |
| 10.9–14.4초 | 새 팬 근접 콘셉트 | 실제 하부 시점을 얻지는 못했음. 앞뒤 차체가 바뀌는 초반을 제외하고 원본 1.55–3초의 팬 디테일만 사용. 실제 하체 배치나 공기 흐름을 입증하는 영상 아님 |

| 17.8–22초 | 사용자 원본 선택 이미지 | ‘아직 무섭다 / 타보고 싶다’, 정지 차량 사진 아님 |

새 각도는 각각 한 번만 사용하며, 원본 길이와 편집 길이가 다릅니다. 로컬 슬로모션·광학 보간으로 길이를 조정했고 유료 재생성을 호출하지 않았습니다. 팬은 짧은 사용 구간을 늘린 만큼 실제 회전 속도를 뜻하지 않습니다. 차량은 흰 차체·검은 휠·차가운 조명으로 묶었지만 샷 사이 세부 디자인이 다릅니다. 동일 실차를 여러 카메라로 촬영한 영상이 아니라 개념 몽타주입니다.

## 음악과 음성

104BPM 전자음악을 로컬에서 오실레이터·시드 고정 잡음으로 직접 합성했습니다. 외부 음원·샘플·음악 API 비용은 없습니다. 낮은 신스·킥·하이햇·짧은 전환음을 넣고, 음성 사이드체인으로 음악 볼륨을 낮춥니다. 음악 단독 목표 -24 LUFS, 합본 목표 -16 LUFS·true peak -1.5 dBTP. 최종 인코딩 측정은 품질 JSON에 기록합니다.

기존 James 남성 내레이션을 그대로 사용합니다. 새 TTS 요청은 없습니다. 청취의 자연스러움·음악 취향을 자동 검사로 확정했다고 주장하지 않습니다.

## 비용·재개

- 새 영상: 4×3초×12크레딧 = **144크레딧**. 승인 한도 전액 사용, 현재 추가 생성 가능 예산 0.
- 이번 새 음성·음악 서비스 비용: 0.
- 프로젝트 누계: 기존 영상 75 + 기존 음성 4 + 새 영상 144 = **223크레딧**, 약 $2.23 상당(세금 제외). 실제 잔액 **777**, 시작 잔액 921 대비 144 감소.
- 생성 작업 ID와 요청 설정은 상태 JSON에 보존하며 키·인증 헤더·서명 URL은 기록하지 않습니다.

파일이 없으면 새 생성 대신 저장된 ID로 조회·다운로드합니다. 결과 URL은 매번 기존 작업 조회 결과에서 얻습니다. 공급자 보관 기간 이후 조회가 불가능하면 사용자 보관본이 필요하며 자동 재생성하지 않습니다.

```bash
.venv/bin/python -m shorts.v4_jobs status --shot wide_descent
.venv/bin/python -m shorts.v4_jobs download --shot wide_descent
# 나머지 이름: rear_nozzle, underbody_fan, wheel_contact
# 기존 v3 음성과 사용자 이미지가 준비된 환경에서 무료 로컬 렌더
.venv/bin/python -m shorts.score
.venv/bin/python -m shorts.first_film_v4
```

`submit`은 완료된 작업에 다시 사용할 수 없도록 차단합니다. 추가 생성은 새로운 승인이 필요합니다. 제작 경과 시간은 비용 표에 기록하며 사람의 노동 시간과 구분합니다.
