## 반영한 선택

- 상단 `AI 콘셉트 · 실제 양산 사양 아님`, 하단 `AI 영상 · 한국어 합성 음성`, 7–24초의 주황색 보조 문구를 제거합니다. 플랫폼 AI 공개 설정과 게시 설명은 유지합니다.
- 정지 차량 사진 컷을 제거합니다. 기존 움직이는 생성 클립과 움직이는 분사·팬 그래픽을 사용하며, 사진 확대를 새 주행 영상이라고 소개하지 않습니다. 기존 1번 영상 재생성 및 신규 차량 영상 생성은 하지 않습니다.
- 사용자 선택에 따라 기초 충격·서스펜션 설명은 한 문장만 남깁니다. 냉가스 추진기와 흡착팬의 역할 차이로 궁금증을 풀어줍니다.
- 친근하고 신뢰감 있는 남성 음색을 목표로 Runway의 Eleven Multilingual V2, James 프리셋을 한 번 합성했습니다. 사용자 승인 상한은 10크레딧, 실제 잔액 차이는 4크레딧입니다. 단일 요청의 무음 구간을 자르고 피치를 유지한 속도 조절로 맞춥니다. 여성 목소리의 단순 피치 변경이나 실제 인물 음성 복제는 하지 않습니다.
- 25–30초는 사용자가 두 번째로 첨부한 ‘아직 무섭다 / 타보고 싶다’ 이미지로 교체합니다. 원본 파일을 확보하기 전에는 다른 그림으로 대체하지 않습니다.

## 비용과 작업 기록

기존 영상 75크레딧 + v2 남성 음성 4크레딧 = 누계 79크레딧. 마지막 실조회 잔액 921. 음성 작업 ID는 `85faff93-22b4-47cf-8852-977a2fba04b3`입니다. `revision-v2-state.json`에 요청·승인 상한·상태·해시·잔액을 비밀값 없이 보존합니다. 음성이나 영상은 자동 재생성하지 않습니다.

```bash
# 기존 음성 작업 재조회·다운로드만 수행
.venv/bin/python -m shorts.revision_voice status
.venv/bin/python -m shorts.revision_voice download
# 아래 편집은 전부 로컬 처리
.venv/bin/python -m shorts.fit_revision_voice
.venv/bin/python -m shorts.first_film_v2 --preview
# 원본 이미지가 assets/choices-user.png에 있고 음성이 준비된 뒤 최종 렌더
.venv/bin/python -m shorts.first_film_v2
```

`--preview`는 교체 이미지가 필요 없는 앞 25초만 내보냅니다. 준비된 승인 남성 음성을 사용합니다. 최종 렌더는 남성 음성과 원본 이미지가 모두 없으면 중단하며 이전 여성 음성·이전 차량 사진을 대신 쓰지 않습니다.

초기 메시지에서는 이미지가 채팅 화면에만 보이고 원본 파일이 실행 환경에 전달되지 않았습니다. PNG를 ZIP으로 압축해 보내는 방법을 안내한 뒤 사용자 ZIP을 수신했습니다. ZIP의 PNG 하나만 직접 읽어 검사했으며 임의 경로로 전체 압축 해제하거나 다른 문서를 실행하지 않았습니다.
