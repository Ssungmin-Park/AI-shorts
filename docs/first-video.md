# 첫 작품: 날아오른 자동차, 어떻게 착지할까?

목표: 30초 숏폼으로 주제 반응 확인. 한국어 시청자 대상. 영상·음성·음악·게시 작업은 아직 완료하지 않았습니다.

**현재 제작 상태:** 세 테스트 생성·다운로드·검수 완료, 총 75크레딧 사용·잔액 925. 추가 생성 예산 0. [완성본 제작 안내](first-film.md), [최신 작업 저널](production-state.json), [검수 기록](pilot-review.md)을 기준으로 이어갑니다. 아래는 최초 계획과 실행 방식의 이력이며, 현재 추가 생성을 승인하는 내용이 아닙니다.

최초 승인된 첫 생성 계획은 Gen-4 Turbo 5초 테스트 3개, 총 15초입니다. 초당 5크레딧 기준 75크레딧($0.75, 세금 제외)을 예상합니다. 추가 테이크와 전체 작품 생성은 테스트 결과를 확인한 뒤 결정합니다. 구매한 1,000크레딧을 한 번에 사용하지 않습니다.

## 30초 대본 초안

| 시간 | 내레이션 | 화면 |
| --- | --- | --- |
| 0–3초 | 차가 날아오르면, 어떻게 내려올까요? | 달빛 이미지의 짧은 체공 장면 |
| 3–8초 | 이건 AI로 상상한 로드스터입니다. 실제 양산 기능은 아닙니다. | 황혼 이미지, 콘셉트 안내 |
| 8–14초 | 착지할 때는 차가 내려오는 속도를 줄여야 합니다. | 하강 방향 화살표와 간단한 도식 |
| 14–20초 | 충격을 완화하면서 차체의 자세도 유지해야 하죠. | 타이어·서스펜션 도식, 차체 균형 표시 |
| 20–26초 | 지면 상태와 바퀴가 닿는 순서도 중요합니다. | 착지 테스트 클립, 접지 지점 표시 |
| 26–30초 | 여러분은 이런 차를 타보고 싶나요? | 차량 이미지와 질문 자막 |

물리 설명은 일반 원리입니다. 이 콘셉트 차량에 실제로 해당 시스템이 탑재되었다고 주장하지 않습니다. 도약보다 착지가 언제나 더 어렵다고 단정하지 않습니다. 내레이션을 녹음한 뒤 실제 발화 길이에 맞게 문장을 조정합니다.

## 첫 테스트 세 개

1. 황혼: 차체를 유지하는 완만한 전진과 카메라 추적.
2. 달빛: 이미 공중에 떠 있는 차량의 낮고 안정적인 체공.
3. 달빛: 짧은 수직 하강과 제어된 착지. 가장 어려운 테스트이며 성공을 보장하지 않습니다.

차체 윤곽, 휠 수와 형태, 헤드라이트, 지면 접촉, 차체의 갑작스러운 변형을 검수합니다. 실패한 장면을 무조건 재생성하지 않고 도식 또는 편집으로 대체할 수 있는지 먼저 판단합니다.

## 실행

기존 60초 TOP 3 프로젝트와 작업 기록이 섞이지 않도록 테스트는 `outputs/pilot-tests/`에 따로 저장합니다.

```powershell
# 비용 없는 설정 검증과 요청 계획 출력
.\.venv\Scripts\python.exe -m shorts.pilot

# 실제 5초 요청 1개: 예상 25크레딧. 키·네트워크 연결 후에만 실행.
.\.venv\Scripts\python.exe -m shorts.pilot --test 1 --execute
```

2번과 3번도 각각 개별 실행합니다. 기존 작업 ID를 재사용하므로 같은 명령을 다시 실행해 조회·다운로드를 이어갈 수 있습니다. API 제출 결과가 불명확하면 자동 재제출을 차단합니다. 예상 소모량은 현재 모델 요율에 대한 계산이며 공급자의 청구 한도를 설정하는 기능은 아닙니다.

## 키 연결: 현재는 클라우드 환경

발급만으로는 이 채팅에서 사용할 수 없습니다. 현재 채팅의 클라우드 실행 환경 설정에서 다음을 등록해야 합니다. 메뉴 이름은 앱 버전에 따라 다를 수 있습니다.

- **비밀값/Secrets 이름:** `RUNWAYML_API_SECRET`
- **값:** Runway에서 발급받은 키를 비밀값 입력란에 직접 붙여 넣습니다. 채팅·GitHub에 입력하지 않습니다.
- **네트워크 허용 호스트:** `api.dev.runwayml.com`

일반 환경변수 대신 비밀값으로 저장하고, Python 실행 중에도 주입되는 설정인지 확인하세요. 저장·적용 후 환경이 다시 시작되면 키 내용을 출력하지 않고 주입 상태부터 점검합니다. 결과 다운로드 주소가 별도 호스트라면 실제 응답을 확인한 뒤 그 호스트에 한해 추가 허용합니다.

Windows 로컬 `.env`에 저장한 키는 이 클라우드로 자동 전달되지 않습니다. 키를 파일로 업로드해서 해결하지 마세요. 비밀값 메뉴를 찾지 못하면 키를 가린 설정 화면으로 위치를 확인할 수 있습니다.
