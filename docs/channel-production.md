# AI 미래 자동차·이동 기술 채널 제작 기준

이 저장소와 현재 주 제작 채팅을 기준으로 기획→사실 확인→소규모 테스트→검수→편집→사용자 게시→성과 기록을 반복합니다. PR #1과 `docs/production-state.json`이 첫 작품의 진행 기준입니다.

## 편집 원칙

2026-10-21 사용자 피드백: 강의처럼 가르치는 흐름보다 시청자가 궁금해하는 ‘그래서 어떻게 되는가’를 먼저 풀어줍니다. 대부분 이미 알 만한 설명은 임의로 길게 넣지 않고 사용자에게 포함 여부를 묻습니다. 이번 작품에서는 기초 충격·서스펜션 설명을 한 문장만 남기고 냉가스 추진기와 흡착팬에 집중하기로 선택했습니다.

유튜브 쇼츠 수정본에는 상단·하단 AI 고정 문구와 주황색 보조 문구를 넣지 않습니다. 공개 표시는 플랫폼 설정과 설명에서 처리합니다. 단, 플랫폼 표시가 자동으로 항상 붙는다고 가정하지 않으며 업로드 시 AI 사용 설정은 직접 확인합니다. 사실·추론·콘셉트는 대본과 게시 설명에서 계속 구분합니다.

정지 차량 사진 컷은 사용하지 않고 실제 움직이는 기존 클립 또는 움직임이 있는 그래픽으로 구성합니다. 단순 확대 편집을 실제 차량 주행 생성이라고 말하지 않습니다. 내레이션 목표는 친근하고 신뢰감 있는 남성 목소리입니다. 비용이 발생하는 목소리 변경·새 서비스 사용은 먼저 알립니다. 이번 수정은 YouTube Shorts에 집중하며 Instagram용 별도 제작은 이번 영상 종료 후 사용자의 다음 지시를 기다립니다.

- 영상마다 시청자의 질문 하나를 정하고, 놀라운 장면→궁금증→쉬운 설명→결론과 질문으로 구성합니다.
- 사실·추론·AI 상상을 구분합니다. 실차 사양이나 제품 발표는 제조사 등 1차 출처로 확인하고, 일반 물리 원리를 특정 양산차 기능으로 바꾸어 말하지 않습니다.
- 반응은 먼저 쇼츠·릴스·틱톡으로 확인합니다. 단일 조회수 급증만으로 롱폼을 결정하지 않고, 비슷한 질문을 여러 번 시험해 시청 유지·완주·저장·질문 댓글이 반복되는지 봅니다.
- 원본 클립을 무조건 늘리거나 재생성하지 않습니다. 부족한 동작은 설명용 도식·원본 이미지·편집으로 대체합니다.

## 비용과 자동화

생성 전 모델·길이·단가·전체 예산·미확정 작업을 점검합니다. 제출 전에 저널에 예약을 기록하며, 응답이 불명확하면 재제출하지 않습니다. 조회·다운로드·렌더는 생성 경로와 분리합니다. 현재 첫 작품의 신규 생성 예산은 0이며 추가 결제나 새 API는 사용자에게 먼저 알립니다.

자동화된 부분: 고정 설정 검증, 예산·중복 제출 차단, 작업 조회·인증 없는 결과 다운로드, 오프라인 음성·자막·도식 렌더, 기술 검사. 자동화하지 않은 부분: 과학 설명의 최종 판단, 주관적 시청 경험, 계정 게시, 성과 해석. 사용자가 직접 게시하기 전까지 계정 작업은 하지 않습니다.

키·인증 헤더·서명 URL은 GitHub·채팅·로그에 보관하지 않습니다. 작업 ID·요청 설정·비용·클립 해시·사용 구간은 비밀값 없이 기록합니다. 생성 영상은 Git에서 제외하고, 파일이 사라지면 같은 ID로 내려받습니다. 공급자 보관 기간이 지나면 사용자 보관본이 필요할 수 있으므로 완성본을 내려받아 보관합니다.

## 측정

`tracking/production.csv`: 비용, 결과물, 기록 가능한 제작 경과 시간. 경과 시간은 사람의 순수 작업 시간과 같지 않으며 기존 채팅의 미계측 시간은 합산하지 않습니다.

`tracking/performance.csv`: 플랫폼·게시 URL·게시 시각·관측 시각·조회수·도달·평균 시청 시간·완주율·좋아요·댓글·공유·저장·팔로워 증가. 플랫폼마다 정의가 다르므로 서로 다른 지표를 같은 뜻으로 합치지 않습니다. 미측정은 빈칸이며 0으로 추정하지 않습니다. 30초 기준 평균 시청 시간을 함께 보면 단순 조회수보다 이해에 도움이 됩니다.

반복해 시청 유지와 질문 반응이 좋은 주제는 3–6분 설명형 롱폼 후보로 확장합니다. 초기 자료가 쌓이기 전에는 임의의 성과 수치나 성공 기준을 확정하지 않습니다.
