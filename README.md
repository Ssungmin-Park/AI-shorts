# AI-shorts

**최신: 장면·음악을 바꾼 22초 YouTube Shorts v4.** [새 장면 검수·편집·음악·게시 문안](docs/revision-v4.md), [작업 ID·비용](docs/revision-v4-state.json), [최종 기술 검사](docs/revision-v4-quality.json). 승인한 Gen-4.5 3초 네 장면을 각각 한 번 생성해 144크레딧 사용. 프로젝트 누계 223·실조회 잔액 777. 남성 음성 재사용, 음악은 무료 로컬 합성. 추가 생성 예산은 모두 소진했습니다.

**v3 이력: 22초 YouTube Shorts.** [질문→반전→역할 차이→선택 흐름](docs/revision-v3.md), [검사·비용 기록](docs/revision-v3-quality.json). 기존 영상과 남성 음성만 재편집해 추가 비용 0, 프로젝트 누계 79크레딧. 서스펜션·독립 도식 화면을 빼고 차량 영상 위에 짧은 그래픽을 겹쳤습니다.

**v2 이력: 30초 수정본.** [요청 반영·수정 대본·출처·남은 작업](docs/revision-v2.md), [v2 작업·비용 저널](docs/revision-v2-state.json). 남성 음성 1회 합성에 실제 4크레딧 사용, 프로젝트 누계 79·잔액 921. 30초 수정본에 남성 내레이션·냉가스 추진기/흡착팬 설명·사용자 제공 선택 이미지를 반영했습니다. 고정 AI 문구와 주황색 보조 문구, 정지 차량 사진 컷을 제거했습니다. 아래 첫 완성본은 v1 이력입니다.

**v1 이력: 첫 30초 착지 설명 영상.** [완성본·대본·출처·로컬 재현](docs/first-film.md), [테스트 검수·재개](docs/pilot-review.md), [작업 ID·비용 저널](docs/production-state.json), [플랫폼별 게시 문안](docs/publishing-copy.md), [채널 운영 기준](docs/channel-production.md)을 확인하세요. 세 테스트 합계 75크레딧 사용, 마지막 실조회 잔액 925. 현재 추가 생성 예산은 0입니다. 기존 테스트의 재개는 `shorts.pilot_session status/download`만 사용하며, 아래 과거 생성 예시는 현재 생성 승인이 아닙니다.

업로드한 로드스터 이미지로 60초·9:16 숏폼을 준비합니다. 기본 명령은 영상 API를 호출하지 않습니다.

**현재 첫 실험은 30초 착지 주제로 진행합니다.** [첫 작품 대본·75크레딧 테스트 계획·키 연결 안내](docs/first-video.md)를 먼저 확인하세요. `python -m shorts.pilot`은 비용 없는 사전 점검입니다. 아래의 60초 TOP 3 구성은 기존 기획으로 보관합니다.

## 현재 가능한 것

- **무료 로컬 시안:** 두 이미지에 느린 확대와 한국어 자막을 적용한 720×1280, 24fps, 60초 MP4. 정지 이미지 편집이며 차량 움직임을 생성한 AI 영상은 아닙니다.
- **제작 자료:** 원래 10개 씬 프롬프트, 참고 이미지 배치, 한국어 내레이션 대본, SRT 자막, 요청 계획.
- **Runway 연동 코드:** 첫 5초 테스트 세 개의 실제 생성·조회·다운로드를 확인했습니다. 작업 ID와 비용을 추적하고 예산·중복 제출을 차단합니다. 결과의 물리적 정확성은 별도 검수가 필요합니다.
- **클립 조립:** 생성된 10개 클립을 지정 길이로 잘라 60초로 편집합니다. 현재 출력은 무음이며 내레이션·음악·효과음은 별도 제작 단계입니다.

유튜브·인스타그램·틱톡 업로드는 아직 자동화하지 않았습니다.

## 이미지와 연출

원본 파일을 이동하거나 변경하지 않고 저장소 루트에서 읽습니다.

| 이미지 | 역할 |
| --- | --- |
| 황혼의 해안도로를 달리는 미래형 슈퍼카.png | 지상 주행·차량 외형의 주 기준 |
| 달빛 아래 비상하는 미래형 하이퍼카.png | 도약·공중 장면의 동작 기준 |

설정은 `config/scenes.json`에서 수정합니다. 두 이미지의 차체 세부 표현에는 차이가 있으므로 일관성은 검수가 필요합니다. 실내·팬·천장 주행·후면 등은 두 장만으로 확정할 수 없어 씬마다 `review_note`를 남겼습니다. 현재 원본의 노을 색감은 보존하며, 최종 Midnight Tech Noir 색보정은 생성 클립을 확보한 뒤 조정합니다.

도약·천장 주행·흡입 팬은 제공된 자료로 검증된 실제 양산 사양이 아닙니다. 초기 시안에서는 영상 내 AI 문구를 사용했습니다. 현재 v4는 사용자 요청에 따라 고정 문구를 제거하고 플랫폼 공개 설정·게시 설명에 AI 콘셉트임을 밝힙니다. 단좌형 차체 변경은 동일 차량 외형을 우선하도록 조정했습니다.

## Windows에서 시작하기

1. 저장소를 PC로 내려받고 Codex에서 그 폴더를 엽니다.
2. Python 3.11 이상을 설치합니다. Windows에서는 설치 시 PATH 추가 항목을 선택합니다.
3. 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m shorts plan
```

`plan`은 API 키 없이 실행할 수 있습니다. `outputs/`에 프롬프트·대본·자막·계획이 저장됩니다. 경로는 스크립트 위치를 기준으로 하므로 한글 폴더 이름도 사용할 수 있습니다.

### 무료 이미지 시안 만들기

[FFmpeg](https://ffmpeg.org/download.html)의 Windows 빌드를 설치하고 `ffmpeg`와 `ffprobe`를 PATH에 추가합니다. PowerShell을 새로 열어 두 명령이 실행되는지 확인하세요. FFmpeg에는 libx264와 libass 지원이 필요합니다.

```powershell
ffmpeg -version
ffprobe -version
.\.venv\Scripts\python.exe -m shorts preview
```

출력: `outputs/final/roadster_storyboard.mp4`. 이 명령은 네트워크·API 키·영상 생성 크레딧을 사용하지 않습니다. 한국어 자막용 글꼴은 **Noto Sans CJK KR**을 권장하며, 글꼴이 없으면 설치된 한글 글꼴로 대체될 수 있습니다. 시안에는 이미지 편집 시안임을 표시합니다.

macOS/Linux에서는 위 Python 경로 대신 `.venv/bin/python`을 사용합니다.

## 실제 움직임이 있는 AI 영상 생성

영상 제작에 결제가 항상 필요한 것은 아닙니다. 웹 서비스의 무료 체험 크레딧이나 로컬 영상 모델을 사용할 수도 있습니다. 다만 **웹 무료 체험과 개발자 API 크레딧은 별개**이고, 로컬 AI 영상 모델은 보통 충분한 GPU와 추가 설치가 필요합니다. 이 저장소에 구성한 Runway API 경로는 계정의 API 이용 권한과 사용 가능한 크레딧이 필요합니다. 무료 크레딧 제공 여부·가격은 서비스에서 직접 확인해야 합니다.

1. [Runway 개발자 플랫폼](https://dev.runwayml.com/)에서 계정을 만들고 API 크레딧·가격을 확인합니다.
2. API 키를 발급합니다. 채팅이나 GitHub 파일에 붙여 넣지 않습니다.
3. `.env.example`을 `.env`로 복사하고 **사용자 PC에서** 키를 입력합니다.

```dotenv
RUNWAYML_API_SECRET=발급받은_키
```

4. 먼저 비용 없는 요청 내용을 확인합니다.

```powershell
.\.venv\Scripts\python.exe -m shorts generate --scene 1
```

5. 다음 명령만 실제 API 요청을 보냅니다. 계정 크레딧이 사용될 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m shorts generate --scene 1 --execute
```

첫 씬의 편집 길이는 3초지만 기본 `gen4_turbo` 요청은 5초로 구성했습니다. 편집 시 앞 3초를 사용합니다. 각 씬에 5초 또는 10초를 요청하므로 전체 요청 길이는 **85초**, 최종 편집은 **60초**입니다. 재시도·추가 테이크 비용은 별도입니다. 모델 이용 가능 여부와 실제 청구액은 현재 계정과 공식 가격표를 확인하세요.

먼저 1개만 생성해 외형과 움직임을 검수한 뒤 `--scene 2`부터 개별 실행합니다. 완료된 클립은 `outputs/clips/scene_01.mp4` 형태로 저장됩니다. 작업 ID는 `outputs/jobs/`에 저장되며 같은 명령을 다시 실행하면 기존 작업을 이어갑니다. 자동 재생성은 하지 않습니다.

제출 중 연결이 끊겨 작업 ID를 받지 못하면 재제출을 차단합니다. Runway 대시보드에서 작업 생성 여부를 확인하고 작업 기록의 ID를 복구하세요. 기록을 무조건 삭제하면 중복 생성으로 비용이 들 수 있습니다. 실패한 작업이나 다른 프롬프트의 새 테이크는 기존 작업을 검토하고 별도로 관리해야 합니다.

현재 클라우드 환경에서 실행하려면 키를 비밀 설정으로 등록하고 `api.dev.runwayml.com` 및 서비스가 반환하는 영상 다운로드 호스트에 대한 네트워크 접근도 필요합니다. 저장소에 키를 넣어 해결하지 마세요.

10개 클립을 확보한 뒤:

```powershell
.\.venv\Scripts\python.exe -m shorts assemble
```

출력은 `outputs/final/roadster_ai_silent.mp4`입니다. 클립이 빠졌거나 짧으면 중단합니다. 짧은 영상을 억지로 늘리지 않으며, 공급자 클립의 오디오는 이 단계에서 제외합니다. 한국어 음성·음악·효과음과 최종 색보정·플랫폼별 게시 설명은 후속 작업입니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

작업 재개·중복 제출 차단·설정 검증을 가짜 API로 검사합니다. 실제 유료 API 요청은 테스트에 포함하지 않습니다. `.env`, 작업 기록, 생성 영상은 Git 추적 대상에서 제외합니다.
